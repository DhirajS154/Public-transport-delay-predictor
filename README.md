# Public Transport Delay Predictor

## Project Overview

The Public Transport Delay Predictor is a full-stack web application designed to help commuters predict possible delays in public transport services. The system uses historical and real-time transport data to provide predictive insights and route status information.

The application allows users to search transport routes, view predicted delays, save preferred routes, and receive notifications about possible disruptions.

---

# Project Objectives

The main objectives of this project are:
- predict possible transport delays
- improve commuter travel planning
- provide route performance insights
- develop a modern full-stack web application
- apply Software Development Lifecycle (SDLC) practices
